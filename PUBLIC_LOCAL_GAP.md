# Public update scope

Comparison date: 2026-11-08.

This branch updates public documentation from the November 3 public milestone. The update summarizes later PHK1 software qualification, the completed offline reliability campaign, PHK2 production-evidence recovery, offline RTL qualification, and the initial synthesis findings.

The public update deliberately does not copy implementation files or raw evidence from private development environments. It contains no physical target identities, lock contents, bitstreams, private binaries, USB traces, production capture payloads, or machine-specific paths. The descriptions distinguish offline software/RTL qualification from synthesis and from silicon qualification.
