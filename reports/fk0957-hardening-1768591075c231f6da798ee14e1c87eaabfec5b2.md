## New defect reproduced in this milestone

`_pinned_ssh()` maps any nonzero SSH return that carries a canonical refusal
envelope to `REMOTE_PROCESS_CONFIRMED_EXITED`. An injected return code 255
(OpenSSH transport failure) plus refusal bytes produces that state, just like
the documented remote refusal status 2. Code 255 does not establish that the
remote process exited; cleanup/ownership must remain unknown. The regression
test is `tests/reference/fk0957_remote_state_audit.py` and reproduces the
misclassification for return codes 255 and 1. Raw stderr remains hidden.
