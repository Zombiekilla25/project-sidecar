## Audit limits

The inherited audit scanned ten lockfiles and 368 unique locked package versions. Twenty-two source/license records in each of the two search candidate locks were unavailable in the local audit cache. The root Rust crate lacks an explicit package license declaration, and some path crates do not have standalone declarations. Some dependencies may be optional or target-specific; missing local metadata is not proof of an incompatible license.

Before external distribution, complete exact source/checksum recovery, active-target dependency resolution, a target-specific SBOM, file-to-license/notice mapping, and written rights for the shipped native binaries. CUDA and NVIDIA components need a separate terms review if bundling is proposed.

## Installation and platform limits

The package pins direct Python requirements but does not provide a fully offline fresh install: the helper can use pip and its bootstrap fetches pinned source revisions with Git. libcudart.so.12 and GPU drivers are not installed by the package. Ubuntu has read-only host preflight only. HiveOS and RabidOS installation/service/driver/rollback support is unverified.

License and provenance gaps are release blockers, not proof of incompatibility.
