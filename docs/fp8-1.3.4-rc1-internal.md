# Sidecar FP8 1.3.4-rc1 internal candidate

This is a private, inactive release candidate; no binary or package archive is included in this repository.

## What was checked

The 1.3.4 internal archive was source-locked (525 entries) and passed 59 focused offline tests. A clean extraction passed the same 59 tests after the documented bootstrap step copies the pinned worker into the build directory. The archive staging installer dry-run reported `apply=false` and did not create the requested prefix. Deploy6, deploy7, and 1.3.3-rc1 remain preserved.

The candidate adds a configuration importer and expands setup wizard fields. Import is dry-run by default, writes only with explicit `--write`, refuses overwrite, and copies secret variable names rather than secret values. Runtime source override fails closed unless it resolves to the pinned upstream tree.

These checks are package and offline checks only. This candidate has not queried a GPU, launched CUDA, connected to a pool, installed a service, or changed production mining. Prior RTX 3080 evidence belongs to other exact releases and does not transfer to 1.3.4. RTX 3060, 3060 Ti, 3070, 3080, and 3090 remain unqualified for this candidate. HiveOS and RabidOS support remains unverified.

## Integration boundary

MIDDLE's R3 source manifest was independently verified. GPU-B separately reports native ABI parity and a patched R3 supervisor smoke that reached `QUEUED`; neither establishes a public share. The frozen R3 candidate still lacks final peer-receipt ingress, and the exact patched supervisor run is not yet a complete candidate-correlated receipt-to-acceptance qualification. R3 is not integrated into this package.

## Redistribution and deployment

External redistribution is blocked pending a complete target-specific dependency/source/license/notice mapping and written rights for any packaged native binaries. This is an unresolved permission/evidence gate, not a finding that every dependency is incompatible.

The package is not installed or activated. Service activation, network mining, payout changes, and developer fees remain disabled. Do not use this candidate for live mining until source-matched runtime, pool receipt, per-device, and redistribution gates close.
