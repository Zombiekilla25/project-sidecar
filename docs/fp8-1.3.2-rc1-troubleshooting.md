# FP8 candidate troubleshooting — 1.3.2-rc1

- **Missing `libcudart.so.12`:** Stop. CPU fallback also links it. The package does not bundle it; establish an approved host runtime source and license terms before installation.
- **GPU inventory empty:** The helper reads `nvidia-smi` metadata only. This is not a CUDA test. Preserve the report and troubleshoot driver visibility without changing a production miner.
- **GPU shown but not in runtime allowlist:** Do not edit runtime pins or substitute device identity. The setup wizard only records selection; it does not authorize or start the device.
- **Profile save refused:** The target already exists, the parent does not exist, or the location is not writable. Use a new private path. The tool never overwrites a profile.
- **Pool URL rejected:** Userinfo, query credentials, and fragments are refused. Keep credentials out of URLs and shell history.
- **Worker does not read profile:** Expected; the prepared profile is not bound into deploy7 runtime. No actual job or share integration is claimed.
- **No accepted public shares:** Offline attempts and local RegressionNet results are not pool shares. Public Testnet2 acceptance remains unverified.
