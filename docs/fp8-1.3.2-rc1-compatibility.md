# FP8 candidate device compatibility — 1.3.2-rc1

NVIDIA's compute-capability table identifies the RTX 3060, 3060 Ti, 3070, 3080, and 3090 as SM86/8.6. Architecture compatibility alone does not qualify an executable or establish network consensus eligibility.

| GPU | Architecture | Candidate status | Network acceptance |
|---|---:|---|---|
| RTX 3060 | 8.6 | Unqualified; no candidate runtime test | Not demonstrated |
| RTX 3060 Ti | 8.6 | Unqualified; no candidate runtime test | Not demonstrated |
| RTX 3070 | 8.6 | Unqualified; no candidate runtime test | Not demonstrated |
| RTX 3080 | 8.6 | Deploy7/1.3.2 candidate not hardware tested; earlier evidence is another release lineage | Not demonstrated for this candidate |
| RTX 3090 | 8.6 | Unqualified; not in deploy7 runtime UUID allowlist | Not demonstrated |

The candidate did not query a GPU or launch CUDA. No model-wide free-VRAM floor or minimum application driver is established. Per-device qualification requires a source-matched executable, exact UUID, memory preflight, isolated approved window, full result verification, and safe rollback. Public Testnet2 acceptance is a separate gate.

Reference: [NVIDIA CUDA GPUs and Compute Capability](https://developer.nvidia.com/cuda/gpus?lng=en-US).
