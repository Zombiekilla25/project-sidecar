# Benchmarks

## GPU baseline

The current research baseline uses NVIDIA Ampere hardware.

A CUDA Redux optimization materially improved the experimental PearlHash GPU kernel relative to the earlier reduction implementation and produced real pool-accepted shares.

Important: experimental kernel throughput and production miner pool hashrate are not automatically interchangeable metrics.

## FK33 compute

FK33 V5.3 has demonstrated:
- functional PearlHash correctness
- resident job reload
- real-pool job handling
- coordinated multi-card operation

The project does not yet claim a pool-accepted PRL share generated by the FK33 V5.3 mining path.

## V7 runtime reliability

The same-generation renewal work fixed the long-job watchdog failure that previously caused card recovery after roughly 150 seconds.

Qualified behavior includes:
- valid same-generation renewals remain active past the old deadline
- wrong/stale renewals are rejected
- generation-change behavior remains valid
- loss of the independent safety supervisor still wins
- controlled coordinator loss still causes authenticated rollback

## PCIe build

Offline PCIe/XDMA V1:
- target: Gen3 x4
- routed
- timing clean
- DRC clean
- hardware resources instantiated
- hardware canary not yet executed

## Sidecar benchmark rules

Every result should report at least:

- GPU-only baseline
- GPU+FPGA end-to-end result
- transfer size
- transfer latency
- FPGA processing time
- synchronization overhead
- overlap strategy
- test duration
- correctness result

Do not report FPGA kernel speed alone as a sidecar speedup.
